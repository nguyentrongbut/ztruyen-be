## Project Overview

**Ztruyện Backend** serves as the API server for the online comic reading portal **Ztruyện**. It handles account creation, local credentials and social logins authentication (Google, Facebook, Discord), user profile customization, avatar frames decorating, comment sections, notification logs, image resolution with referer restriction, media uploading buffers via Telegram API, Firebase-based push notifications, and admin dashboard statistics telemetry.

---

## Quick Reference

- **Tech Stack:** NestJS (v9.4.0), TypeScript (v4.9.5), MongoDB, Mongoose (v7.1.0), Passport, Firebase Admin, Resend
- **Entry Point:** `src/main.ts`
- **Architecture Pattern:** Modular MVC / Controller-Service-Schema (Mongoose ODM)
- **Database:** MongoDB (NoSQL)
- **Deployment:** Azure Web App (App Service - Node.js) via GitHub Actions CI/CD

## Getting Started

### Prerequisites

Ensure you have the following installed:
- Node.js (version 18.x or higher)
- NPM
- A running MongoDB instance (local or remote MongoDB Atlas)

### Setup

```bash
npm install
cp .env.example .env
# Edit .env file with your specific secrets keys and database connection URL
```

### Run Locally

```bash
npm run start:dev
```

### Run Tests

```bash
npm run test
npm run lint
```
